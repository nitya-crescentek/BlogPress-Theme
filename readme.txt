== Description ==

BlogPress is a lightweight WordPress theme built with a focus on speed and usability. Performance is important to us, which is why a fresh BlogPress install adds less than 10kb (gzipped) to your page size.

We take full advantage of the block editor (Gutenberg), which gives you more control over creating your content.

If you use page builders, BlogPress is the right theme for you. It is completely compatible with all major page builders, including Beaver Builder and Elementor.

Thanks to our emphasis on WordPress coding standards, we can boast full compatibility with all well-coded plugins, including WooCommerce.

BlogPress is fully responsive, uses valid HTML/CSS, and is translated into over 25 languages by our amazing community of users.

A few of our many features include 60+ color controls, powerful dynamic typography, 5 navigation locations, 5 sidebar layouts, dropdown menus (click or hover), and 9 widget areas.

== Installation ==

= From within WordPress =
1. Visit "Appearance > Themes > Add New"
1. Search for "BlogPress"
1. Install and activate

== Frequently Asked Questions ==

= Is BlogPress Free? =
Yes! BlogPress is a free theme, and always will be.

= Where can I find the theme options? =
All of our options can be found in the Customizer in 'Appearance > Customize'.

= Does BlogPress have any widget areas? =
BlogPress has up to 9 widget areas which you can add widgets to in Appearance > Widgets.

= How can I make my site look like your screenshot? =
If you want to replicate the screenshot you see on WordPress.org, please refer to [this article](https://docs.blogpress.com/article/replicating-the-screenshot/).
